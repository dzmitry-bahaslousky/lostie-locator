# Lostie Locator

An app that helps people find lost pets: owners post lost-pet requests,
people nearby report sightings, and finders post pets that look lost.

## Read first

Before working on anything, read the project docs:

- `docs/vision.md`: what we are building and why.
- `docs/requirements.md`: user flows, MVP scope, out of scope.
- `docs/design.md`: screens, visual style and logo.
- `docs/tech.md`: stack and technical choices.
- `docs/moderation.md`: how we fight spam, scams and fake reports.
- `docs/decisions.md`: decisions already made; don't reopen them without asking.

When a decision is made in conversation, add it to `docs/decisions.md`.
